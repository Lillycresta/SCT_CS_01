Operation
XOR Cipher
Each pixel channel XOR'd with a key-derived value. Symmetric — same key encrypts & decrypts.
Invert + Offset
Inverts pixel values (255−x) then shifts by key modulo. Simple but visually dramatic.
Channel Shuffle
Permutes RGB channels per pixel based on key. Decrypt reverses the permutation.
Row Scramble
Shuffles pixel rows using a seeded PRNG derived from the key. Reverses on decrypt.
Bit Rotation
Rotates each channel's bits by a key-derived shift amount. Fully reversible.
Encryption Key
Any string or number. Must match
for successful decryption.
